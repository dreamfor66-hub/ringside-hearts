# 이미지 프롬프트 목록 v0.1 — 사용자가 돌릴 캐릭터와 추천 프롬프트

작성일: 2026-11-17
연결 문서: [아트-제작-가이드-v0.1.md](아트-제작-가이드-v0.1.md), [캐릭터-로스터-확장-v0.1.md](캐릭터-로스터-확장-v0.1.md), [캐릭터-설정집-v0.1.md](캐릭터-설정집-v0.1.md)

이미지는 사용자가 뽑고, Claude는 프롬프트와 이후 가공·등록을 맡습니다 (아트 가이드 2.2). 프롬프트는 사용자 그림 17장의 생성 정보에서 읽은 형식을 그대로 따랐습니다. 태그는 출발점일 뿐이니 마음대로 바꿔 쓰세요.

---

## 0. 공통

### 설정 (사용자 기존 값)
- 모델 V4.5 Full, 832×1216, 25스텝, 가이던스 6.3, Euler Ancestral, karras, 부정 프롬프트 비움
- **각성**: 확정한 스탠딩을 캐릭터 레퍼런스로 (character&style, 강도 0.85~0.9, 보조 강도 0.1~0.25)

### 틀
각 캐릭터의 태그는 아래 `<캐릭터 태그>` 자리에 들어갑니다. 목록에는 이 자리의 내용만 적었습니다.

```
{{live a hero}}, {white bg}, single character, male, wrestler, furry, full body, <캐릭터 태그>

,[[[world flipper]]], housamo, {{live a hero}}, very aesthetic, masterpiece, no text
```

### 룽웨이·빨간 드래곤에서 확인한 것
| 상황 | 해결 |
|---|---|
| 스탠딩에 이펙트가 들어감 | 끝에 `no effect` |
| 무술복처럼 바뀌어 레슬러로 안 보임 | 마스크, 트렁크, 무릎 보호대, 끈 맨 부츠를 넣음. 종족 테마는 무늬와 소품으로만 |
| 팔다리가 화면 밖으로 잘림 | `full body` (틀에 이미 있음) |
| 각성이 뛰어오르기만 하고 무슨 기술인지 안 보임 | 기술 이름 + `attack pose` + 이펙트 한 단어. 하이킥, 올려치기, 낮게 웅크린 다리 걸기, 날아 옆차기가 잘 나옴 |
| 머리가 여러 개 나옴 | `twin dragon heads`처럼 "여러 개"로 읽힐 단어를 쓰지 않음 |
| 레퍼런스를 넣으면 원본 구도를 그대로 따라감 | 강도를 0.7까지 낮추고 `side view`, `from below`, `standing on top rope`처럼 카메라와 장소를 줌 |
| 수염, 털색 같은 작은 특징이 사라짐 | 그 특징 태그를 각성 프롬프트에 다시 넣음. 아래 목록의 각성 태그에 미리 넣어 둠 |
| 구도는 좋은데 인상이 달라짐 | 그 그림을 바탕으로 img2img 0.5~0.65 |
| 손가락이 6개 | 손 부분만 인페인트 (세기 0.6~0.75) |
| `double biceps`, `provocation pose`에서 가슴 색이 주황·노랑으로 바뀜 | 몸 색 태그를 다시 넣음 |

### 확정본 넘기는 곳
`ArtRaw/{id}/standing.png`, `ArtRaw/{id}/awakened.png`로 넣고 알려 주시면, Claude가 배경 제거, 규격 자르기, 썸네일, 데이터 등록을 합니다. `{id}`는 각 캐릭터 제목 옆에 적었습니다.
