# 전투 프로토타입 설계 v0.2 — 한 번에 크게 만드는 게임 테스트

작성일: 2026-11-18 · 이전 판: [v0.1](전투-프로토타입-설계-v0.1.md) (단계별로 쌓던 판. 6장 물리, 10.2 화면 3칸, 4.1 같은 캐릭터 구조는 그대로 이어받음)

## 0. 원칙 [확정 2026-11-18]
- 프로토타입은 기능 확인이 아니라 **질 수 있는 게임**. 밸런스는 봇 대전으로 맞추고 숫자를 보고함
- **한 번에 크게** 만들어 넘김. 그레이박스는 아트가 없다는 뜻이지 볼륨이 작다는 뜻이 아님
- **양손** 입력: 왼손 = 마우스 왼쪽 / A / 화면 왼쪽 절반, 오른손 = 마우스 오른쪽 / D / 화면 오른쪽 절반
- 고무줄 난이도 금지 (처음엔 못 이기다가 반복하면 저절로 쉬워지는 구조). 유불리는 화면에 보이는 상태로만
- 도구(캐릭터, 기술)와 문제(링 위 상황)가 둘 다 풍부해야 함
- 아래 규칙과 숫자는 전부 [임의]. 만들어서 보여 드리고 플레이 후 고침

## 1. 한 판의 모양
- 3:3 태그 매치가 기본. 링 안에 팀마다 1명, 나머지 2명은 에이프런(로프 밖 띠)에 섬
- 목표 길이: **20턴 안팎, 6~10분**. 턴 제한 30
- 승리: 상대 한 명에게 피날레(핀폴, 서브미션, 링아웃) 성공. 패배: 내 선수가 피날레를 당하거나 턴 제한

## 2. 턴
- **교대제**: 한 턴 = 내 팀 행동 1번 + 상대 팀 행동 1번. 1:1에서 한쪽만 여러 번 움직이지 않음
- 내 행동: (태그 1회, 무료) → 샷 / 필살기 샷 / 어필 / 버티기(링 안 선수가 다운일 때) 중 하나
- **필살기 카운트** (몬스터 스트라이크의 공격 카운트를 옮김): 선수마다 숫자가 있고(캐릭터 데이터, 4~6) 턴 끝마다 −1. 0이면 필살기 샷 가능. 대기 중에도 줄어듦 → "카운트 찬 동료를 태그로 넣기"가 판단이 됨. 쓰면 다시 처음 값
- 상대 선수의 카운트도 머리 위에 보임. 0인 상대 선수가 링에 있으면 다음 상대 행동은 필살기

## 3. 링 위의 것들 (문제 쪽 깊이)
- **에이프런의 대기 선수**: 로프 바로 밖에 섬. 샷이 로프를 밀고 나가며 대기 선수에게 닿으면
  - 내 동료: **어시스트** 발동 (동료마다 다름, 5장). 한 샷에 동료당 1번
  - 상대 대기 선수: 에이프런에서 **떨어뜨림** → 2턴 동안 태그와 어시스트 불가
- **코너 턴버클**: 샷이 코너 근처(코너에서 1.6 이내)에 멈추면 "코너 위". 다음 샷의 첫 타격 위력 ×1.6 (다이브)
- **심판**: 링 위를 걷는 몸(작은 원). 샷에 맞으면 2턴 동안 다운 → 그동안 핀폴 카운트 불가. 핀폴은 심판이 멀수록 카운트가 늦게 시작됨. 턴마다 링 안 두 선수 근처로 걸어감
- **매치 장치** (6장): 케이지 철망, 하드코어 의자와 테이블

## 4. 피해, 다운, 피날레
- 두 가지 체력: **스태미나**(0이면 다운, 기상 때 회복) + **바디**(누적 피해, 회복 없음). 바디 피해 = 피해 × 0.4
- 타격 피해 = 파워 × 피해 배율 × 반동 보너스(쏜 선수 반동 1회 +15%, 최대 3회) × 속성(유리 ×1.3, 불리 ×0.8) × 열기(±10%, 열기 의존 캐릭터 ±30%) × 타입 × 라리아트(×1.5) × 필살기 배율 × 다이브 ×1.6
- 다운: 매 턴 끝 스태미나 회복 (15% + 근성 × 0.03%), 30%면 기상
- **다운된 선수는 로프 근처에 쓰러져 있을 때만 태그로 빠질 수 있음** (로프까지 기어가 손을 뻗는 것). 상대를 링 중앙에서 눕히면 구조가 막힘 → 그래플러의 중앙 던지기가 의미를 가짐 [만들며 추가: 처음엔 구조가 공짜라 피날레가 거의 안 나왔음]
- 다운된 선수가 맞아도 피해 없음, 닿으면 그 팀의 플랜으로 **피날레 즉시 발동** (샷을 그 순간 끊음)
- **링아웃**: 닿는 순간 상대를 붙잡아 내 반대 방향으로 로프까지 밀어붙임. 밀어붙인 거리 1당 넘김 게이지 시작값 −5 (로프 옆에서 걸면 유리, 중앙에서 걸면 불리) [만들며 바꿈: 처음엔 일반 물리로 로프에 부딪혀야 했음]
- 한 샷에서 다운을 만들었으면 그 샷의 나머지 접촉으로는 피날레 없음
- **피날레 힘**: 공격 A = 파워/100 × 열기 배율(×0.8~1.2) × 세컨드 보정, 방어 D = 근성/100 × (0.1 + 0.9 × 바디 잔량) × (필살기로 다운됐으면 0.7). 숨은 보정 없음. 첫 다운에선 빠른 연타(초당 9 정도)여야 끝나고, 바디가 깎일수록 쉬워짐
- 실패하면 방어 측이 30%로 일어나고 공격 측 열기 +10

## 5. 캐릭터
- 15명 + 보스(마운틴 버스터). 데이터: 진영, 속성, 타입, 체인 역할, 등급, 스태미나, 파워, 근성, 열기 의존, 어필 열기, 필살기(이름, 배율, 카운트), 어시스트, 세컨드 스킬
- **타입 5종** (v0.1 7장 그대로): 스트라이커(로프 전 타격 ×1.4, 밀어내기 ×1.6), 쇼메이커(반동 보너스 +30%, 반동마다 열기 +5), 그래플러(처음 닿은 상대를 붙잡아 링 중앙으로 던짐, ×1.2), 스탬피더(뚫고 지나감, 상대는 0.6배만 밀림), 하이플라이어(처음 로프에서 뛰어 3.5 날아가 착지 반경 2.0 타격 ×1.3). 필살기 샷에서 강해지는 것도 v0.1 7장
- **어시스트 4종**: 라리아트(대기 위치에서 링 중앙 방향 직선 폭 1.4, 파워 ×1.0), 스톰프(닿은 지점 반경 2.5, ×0.7), 함성(열기 +15), 아이싱(링 안 동료 스태미나 +8%)
- **세컨드**: 짝에게 능력치 20%, 세컨드 스킬(효과 블록 v0.1 9.2), 힘겨루기 중 개입 1회(페이스: 3초 동안 내 입력 ×1.5 / 힐: 2초 동안 상대 쪽 멈춤 + 심판 경고)
- **태그 체인**: 선봉 → 연결 → 마무리 순서로 자기 행동에서 상대를 맞히면 칸이 켜짐. 3칸이면 마무리 선수의 다음 샷이 합동 필살기(×4), 체인 초기화

- **어필**: 한 행동을 써서 열기 +25~40(힐 ×1.5, 대신 심판 경고), 그리고 **어필한 선수의 필살기 카운트 −1** [만들며 추가: 열기만으로는 행동 한 번 값을 못 했음]

## 7. 힘겨루기 (양손)
| | 공격 측 | 방어 측 |
|---|---|---|
| 핀폴 | 왼손·오른손 **번갈아** 연타로 누르기 게이지 유지. 게이지가 50 이상이면 심판 카운트(0.8초 간격, 심판 거리만큼 늦게 시작). 3카운트 승리 | **킥아웃 타이밍**: 카운트마다 원이 줄어들고, 표적 원에 겹칠 때 **양손 동시**에 누름. 판정 폭은 바디 잔량에 비례. 성공하면 킥아웃 |
| 서브미션 | 번갈아 연타로 조이기 게이지 0→100 (100이면 기브업) | 번갈아 연타로 **로프까지 기어가기** 0→100 (로프 근처면 60에서 시작, 100이면 로프 브레이크). 6초 지나면 탈출 |
| 링아웃 | 흔들리는 바늘이 **바깥 끝**에 왔을 때 양손 동시 → 밀어 넘기기 | 바늘이 **안쪽 끝**에 왔을 때 양손 동시 → 끌어당기기. 넘김 게이지 100이면 링아웃, 0이면 복귀 |
- AI 쪽은 같은 규칙을 정해진 실력값(연타 속도, 타이밍 오차)으로 수행. 힘은 파워·근성·열기·바디로 정해지고 숨은 보정 없음

## 9. 연출과 손맛 [2026-11-19 사용자 피드백 반영]
- **필살기**: 시간이 멈추고 화면이 어두워진 뒤, 속성색 띠와 각성 일러스트, 기술 이름이 들어오는 컷인(1.15초). 합동 필살기는 세 명
- **필살기 타이밍 2종** (characters.csv `special_timing`): `발사` = 놓는 순간 컷인(스트라이커, 그래플러, 스탬피더). `로프` = 처음 로프에 닿는 순간 로프가 크게 당겨진 채 멈추고 컷인, 박차면서 속도 ×1.25 (쇼메이커, 하이플라이어, 토로)
- **스트라이커 직격**: 추가 히트스톱 + 화면 흔들림 + 충격파 + "직격!"
- **쇼메이커 반동**: 튕길 때마다 오라가 커지고 색이 바뀌며 "반동 ×2 +60%", 최대면 "MAX!"
- **하이플라이어**: 날아오르는 동안 몸이 위로 뜨고 커지며 그림자는 바닥에 남음. 착지에 충격파
- **그래플러**: 잡는 순간 멈춤 + "잡았다!", 상대를 들어 링 중앙으로 빠르게 던져 내리꽂음(슬램, 피해는 내리꽂는 순간). 테이블이 중앙에 있으면 테이블에 꽂힘
- **스탬피더**: 잔상, "관통!"
- **라리아트 어시스트**는 링을 가로지르는 직선, 스톰프는 충격파
- 피해 숫자는 크기가 피해량에 비례. 다운은 슬로모션 + "DOWN!"
- **심판 경고**: 힐 어필 때 심판 머리 위 옐로카드와 "경고 n/3"
- **턴 배너** "내 차례/상대 차례", 상대 필살기가 준비되면 빨간 경고 배너와 유닛·카드의 배지가 빨갛게 뜀
- **피날레 연출**: 핀폴·서브미션은 닿는 순간 멈춰 번쩍임과 "덮쳤다!/걸었다!", 링아웃은 상대를 잡고 로프까지 밀어붙이는 장면. 그다음 힘겨루기
- **힘겨루기 인트로** 1.8초: 게이지 고정, 입력 무시, 손 패드가 필요한 리듬(번갈아 ⇄ / 동시에 ＋)을 시연, "준비 2·1" → "시작!". 모두 같은 시간을 받고, 먼저 누를 수 없음
- 손 패드는 맞게 누르면 초록, 같은 손 두 번이면 빨강. 타이밍 창이 열리면 패드가 함께 빛남
- 상황 칩: 방어 측 바디, 필살기 다운 여부, 심판 거리, 로프 근처, 밀어붙인 거리, 열기 배율, 경고 누적

## 10. 화면
- v0.1 10.2의 세로 3칸 그대로. 상단: 턴, 상대 링 안 선수 카드, 상대 체인, 상대 열기, 매치 규칙, 기록·디버그 버튼. 하단: 열기 게이지, 내 체인, 플랜 줄, 내 선수 3명 카드(누르면 태그), 어필·필살기 버튼
- 유닛: 속성색 원 + 이름 + 타입 글자, 스태미나 고리, 바디는 고리 안쪽 얇은 고리, 머리 위 필살기 카운트
- 대기 선수는 에이프런 위 80% 크기, 자기 고리와 카운트, 태그 잠금·떨어짐 표시
- 피해 숫자와 배율 태그는 맞는 순간, 카드 바도 그 순간 줄어듦
- 전투 밖: 매치 선택 → 편성 → **VS 화면**(양 팀 스탠딩 일러스트) → 전투 → **결과 화면**(WIN/LOSE, 피니시한 선수의 각성 일러스트, MVP, 숫자 타일)
- **편성** (월드플리퍼식): 세로로 긴 3칸. 각성 일러스트, 이름·★, 타입 아이콘·역할 점, 속성·진영, 스탯 막대(스태미나·파워·근성), 아이콘 버튼(필살기·어시스트·타입 → 설명 팝업), 아래 세컨드 칸. 그림을 누르면 선수 선택, 세컨드 칸을 누르면 세컨드 선택(일러스트 타일 격자)
- **아이콘**: 타입 = 모양(스트라이커 별, 쇼메이커 다이아, 그래플러 갈퀴, 스탬피더 화살촉, 하이플라이어 날개), 역할 = 점 1·2·3개, 어시스트 = 손. 링 위 유닛에도 타입 모양
- 일러스트가 없는 캐릭터(터스크, 타누, 오티, 잭, 데스롤, 마운틴 버스터)는 속성색 판 + 이름 + 타입 모양으로 대신함
- 한 판 기록은 기기의 `battle_log.csv`에 한 줄씩
