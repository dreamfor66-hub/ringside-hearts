- 출시 24명 기준: 생성 약 170장, 인페인트 약 120장. 얼터 3장은 스탠딩, 각성, SD만 추가

## 2. 생성 방식 — NovelAI V4.5 Full Furry [확정]

### 2.1 사용자 방식을 표준으로

1. **고정 태그를 먼저 정함**: 종, 색, 체형, 대표 기술 포즈 (예: `cat, yellow, teal, slim, acrobatic kick, windmill, upside down`)
2. 공통 태그 + 고정 태그로 반복 생성. 약 50회 중 1장이 쓸 만함
3. 스탠딩이나 각성 중 **먼저 나온 쪽을 캐릭터 레퍼런스(캐릭터만 고정)**로 넣고 다른 쪽을 생성
4. SD, 마사지, 표정도 같은 원리. **확정된 기준 그림을 레퍼런스로** 넣고 만듦

NovelAI 공식 문서 기준으로 알아 둘 것
- 캐릭터 레퍼런스는 V4.5 모델 전용이고, 아직 프리뷰 기능
- 캐릭터 레퍼런스와 바이브 트랜스퍼는 함께 쓸 수 없음
- 한 번에 레퍼런스 1장

### 2.2 역할 분담 [확정, 2026-11-17]

룽웨이를 직접 뽑아 본 뒤 정한 방식입니다.
- **사용자**: 이미지 생성과 선택. 뽑기는 결국 얻어걸릴 때까지 돌리는 작업이라 사용자가 하는 쪽이 빠름
- **Claude**: 캐릭터별 추천 프롬프트 목록([이미지-프롬프트-목록](이미지-프롬프트-목록-v0.1.md)), 확정본을 게임에 넣는 가공과 등록, 구조 설계와 코딩
- 사용자가 확정본을 `ArtRaw/{id}/`에 `standing.png`, `awakened.png`로 넣으면 Claude가 배경 제거, 규격 자르기, 썸네일, 데이터 등록을 함

아래 단계 A·B는 처음 세운 계획으로, 참고로 남겨 둡니다. API 연결과 `Tools/NovelAI/nai_gen.py`는 그대로 쓸 수 있습니다.

**단계 A — 지금 바로 (설정 없음)**
- 캐릭터별 태그 작성 (로스터 문서 5장처럼)
- 사용자가 뽑은 후보를 폴더에 넣으면 Claude가 직접 보고 검수
  - 설정과 맞는지: 색, 마스크, 소품, 속성 팔레트
  - 손가락, 관절, 소품 오류
  - 수위 기준 (4장)
  - 기준 그림과 같은 캐릭터로 보이는지
- 확정본 가공: 배경 제거, 규격 자르기, 썸네일, 파일 이름 규칙(6장)에 맞춰 게임 폴더에 넣고 데이터에 등록

**단계 B — NovelAI API를 연결하면**
- Claude가 같은 태그로 한 번에 수십 장을 생성하고, **직접 보고 5장 정도로 추림**. 사용자는 최종 1장만 고름
- 사용자가 할 일
  - NovelAI 계정 설정에서 영구 API 토큰을 발급
  - 이 PC의 환경 변수(예: `NOVELAI_TOKEN`)에 넣기. 토큰 값은 대화에 붙이지 않음
- 연결할 때 확인할 것
  - 1장당 Anlas 소모량. 구독 등급, 이미지 크기, 레퍼런스 사용 여부에 따라 달라서 처음에 10장으로 시험
  - NovelAI 약관의 API 사용 조건
- 효과: 사용자의 일이 "50장 돌리기"에서 "5장 중 고르기"로 줄어듦

### 2.3 남겨 둘 것

- 확정본마다 **태그, 시드, 모델, 쓴 레퍼런스 그림**을 함께 저장 (나중에 같은 캐릭터를 다시 뽑을 때 필요)
- NovelAI 원본 PNG에는 생성 정보가 들어 있으니 원본을 지우지 않음
- 후보 원본은 용량이 커서 게임 저장소 밖에 두고, 확정본만 저장소에 넣음
  - 실제 위치: 저장소 안의 `ArtRaw/` 폴더. `.gitignore`에 넣어 Git에는 올라가지 않음

### 2.4 스탠딩과 각성 규칙 [확정, 2026-11-17 사용자 피드백]

참고 일러스트 10장의 왼쪽(스탠딩)과 오른쪽(각성)을 기준으로 삼습니다.

| | 스탠딩 | 각성 |
|---|---|---|
| 이펙트 | **거의 없음.** 흰 배경에 선수만 | 속성 색 이펙트를 크게 |
| 포즈 | 서 있는 전신, 정면이나 살짝 비스듬히. 성격이 보이는 손짓 하나 | **무엇을 하는지 한눈에 보이는 타격 동작**(펀치, 킥, 태클, 촙, 래리엇)이나 공격 준비 자세 [확정, 2026-11-17 사용자 피드백]. 뽑고 싶은 장면이 따로 정해진 경우만 예외 |
| 태그 처리 | 이펙트 계열 태그를 부정 프롬프트에 넣음 (`prompts.json`의 `variant_negative`) | 이펙트 태그를 넣음 |

**레슬러 표지 4가지는 모든 선수에게 넣습니다.**
- 머리 전체를 덮는 루차 마스크 (집사 버나드처럼 마스크가 없는 캐릭터는 예외)
- 짧은 트렁크나 타이츠
- 무릎 보호대
- 끈을 맨 두꺼운 레슬링 부츠

각성 포즈에서 피할 것
- 그냥 뛰어오르거나 몸을 비트는 "동적이기만 한" 포즈. 무슨 기술인지 안 보임
- 상대가 있어야 성립하는 기술(수플렉스, 베어허그). 그림에는 선수 혼자라서 어색해짐 → 잡으러 들어가는 준비 자세로 바꿈
- 팔이나 다리를 화면 쪽으로 내미는 원근 구도(`toward viewer, foreshortening`)를 쓰면 타격이 잘 읽힘

각성 구도에서 사용자가 좋아하는 것 [2026-11-17 피드백]
- **삼각 구도**: 넓게 벌린 두 발이 밑변, 머리나 내지른 손이 꼭짓점. 빨간 드래곤 D8을 뺀 이유가 이것
- **스탠딩 자세에서 이어지는 동작**: 빨간 드래곤의 낮은 태클 준비 자세 → 로우앵글로 이어지는 D6처럼
- 땅을 디딘 자세가 정적으로 보이면 동작은 그대로 두고 **카메라를 움직임**: `dynamic angle, low angle camera, dutch angle, twisting body, foreshortening`. 점프는 부정 프롬프트로 막음
- 레퍼런스 강도는 **0.85~0.9가 기본**. 원본 구도가 그대로 따라오면 0.7까지 낮추고 카메라와 장소(`from below`, `standing on top rope`)를 지정

구도 유형을 바꿔 가며 찾기 (룽웨이 6종 × 8장에서 확인한 것)
| 유형 | 결과 |
|---|---|
| 하이킥·후려차기 (`spinning hook kick, one leg extended high`) | 가장 좋음. 다리가 꼭짓점인 세로 삼각 구도, 무술과 레슬링 부츠가 함께 읽힘 |
| 올려치기 (`rising uppercut, fist raised high`) | 좋음. 용 기운이 몸을 감고 올라가는 영웅 구도 |
| 뒤돌아보기 (`from behind, looking back over shoulder`) | 등 근육과 꼬리가 주인공. 다른 각성과 확실히 구분됨 |
| 래리엇 (`lariat, side view, running`) | 보통 |
| 돌진 태클 (`charging, low tackle`) | 공중에서 몸을 마는 그림이 많아 읽기 어려움 |
| 쌍장 (`twin dragon heads`) | **실패.** 머리가 셋 달린 캐릭터가 나옴. "여러 개의 머리"로 읽힐 단어는 쓰지 않음 |

종이나 속성의 테마(동양 무술, 귀족, 기계)는 **무늬, 색, 소품으로 얹습니다.** 테마가 옷 자체를 바꾸면 레슬러로 안 보입니다. 첫 룽웨이 시험(무술 바지, 맨발)이 그랬습니다.

### 2.4.1 사용자 작업 패턴 [2026-11-17, 사용자 그림 17장의 생성 정보에서 읽음]

NovelAI는 그림의 투명도 채널에 생성 정보를 숨겨 둡니다. 무손실 webp로 받은 그림에서도 읽힙니다 (`nai_gen.py readmeta`). 스크립트 설정을 이 패턴에 맞췄습니다.

| 항목 | 사용자 방식 |
|---|---|
| 모델 | V4.5 Full (`4BDE2A90`). `fur dataset` 태그는 쓰지 않음 |
| 앞부분 | `{{live a hero}}, {white bg}, single character, male, wrestler, furry` |
| 뒷부분 | 빈 줄 다음 `,[[[world flipper]]], housamo, {{live a hero}}, very aesthetic, masterpiece, no text` |
| 강조 | live a hero는 올리고 `{{ }}`, world flipper는 크게 내림 `[[[ ]]]` (곰은 `[[[[[[ ]]]]]]`까지) |
| 캐릭터 태그 | 짧게: 색 1~2개 + 종 + 특징 2~4개 + 동작. 의상은 거의 적지 않음 |
| 부정 프롬프트 | 비움. 가끔 `::clothes tore::` |
| 설정 | 25스텝, 가이던스 6.3, k_euler_ancestral, karras |
| 순서 | 액션(각성)을 먼저 뽑고, 그걸 레퍼런스로 스탠딩을 뽑는 경우가 많음 |
| 레퍼런스 (각성 쪽) | character&style, 강도 0.8~0.9, 보조 강도 0.1~0.25 |
| 레퍼런스 (스탠딩 쪽) | character, 강도 0.9~1.0, 보조 강도 0~0.65 |
| 레퍼런스를 넣으면 | 의상과 체형 태그를 지우고 동작과 이펙트만 남김. 그래서 태그가 짧아 보임 |
| 스탠딩 동작 | `stand`, `standing pose`, `crossed arms`, `hand waist`, `provocation pose` + `no effect` |
| 각성 동작 | `tackle, attack pose`, `diving body press`, `flying straight kick`, `whirlwind kick`, `punching`, `charge` + 이펙트 한 단어 (`fire`, `electricity`, `energy`, `storm`) |
| 그 밖 | 노이르와 래프의 스탠딩은 Img2Img로 다듬음. 노이르는 `low angle camera, look at camera` |

## 3. 전투 SD

### 3.1 결정 [확정]
- **보드 위에 캐릭터가 서 있는 SD** (몬스터 스트라이크, 서몬즈 보드, 월드 플리퍼처럼)
- 얼굴을 자른 원형 토큰은 **프로토타입에서만** 씀

### 3.2 일러스트 SD로 [임의 A1]

|  | 일러스트 SD (몬스트, 서몬즈 보드 방식) | 픽셀 SD (월드 플리퍼 방식) |
|---|---|---|
| 만드는 법 | 스탠딩을 레퍼런스로 NovelAI 생성 후 정리 | 프레임마다 도트 작업. AI로 뽑으면 프레임마다 모양이 흔들림 |
| 한 명당 양 | 포즈 3장 | 대기, 이동, 공격, 피격, 다운 등 수십 프레임 |
| 움직임 | 코드로 늘이기, 기울기, 잔상, 흔들림 | 프레임 애니메이션이라 생동감이 큼 |
| 매달 신규 추가 | 지금 파이프라인으로 가능 | 도트 작업자가 필요 |

지금 파이프라인으로 매달 신규를 낼 수 있는 쪽이 일러스트 SD입니다. 픽셀 SD는 도트 작업자를 둘 수 있을 때 다시 봅니다.

### 3.3 포즈 3장 [임의 A2]

| 포즈 | 쓰는 때 |
|---|---|
| 대기 | 정면에서 살짝 비스듬히 선 자세. 에이프런 대기도 이 그림 |
| 돌진 | 쏘아질 때. 몸을 앞으로 기울인 자세 |
| **다운** | 누운 자세. 핀폴과 서브미션 대상이 링 위에 누워 있어야 해서 꼭 필요 |

코드로 넣는 연출
- 대기 중 숨쉬기 (위아래로 살짝 늘었다 줄어듦)
- 쏘기 직전 웅크림, 이동 중 기울기와 잔상
- 충돌 때 흔들림과 번쩍임, 로프 반동 때 찌그러짐
- 다운 때 머리 위 별, 태그 때 로프를 넘는 점프

### 3.4 규격 (프로토타입에서 조정)
- 원본 512×512 투명 PNG, 발 가운데에 기준점
- 링 위 크기는 화면 가로의 약 1/7, 에이프런 대기는 그 80%
- SD 태그 예: `chibi, super deformed, full body, standing, simple shading, white background` + 캐릭터 고유 태그 + 스탠딩 레퍼런스

## 4. 수위 기준 (커트라인)

사용자가 정한 기준을 그대로 정리하고, 자리별 단계와 처리 방법을 붙였습니다. 참고 기준은 GYEE와 XXL Woofia의 앱스토어 버전입니다. [확정]

### 4.1 전제
- **모든 플레이어블과 서비스 장면에 나오는 캐릭터는 성인(20세 이상)이고, 외형도 성인 체형**
- 그래서 터스크를 "10대 후반"에서 **20세 신인**으로 바꿉니다

### 4.2 허용 범위

| 구분 | 내용 |
|---|---|
| **허용** | 엉덩이 라인, 찢어진 코스튬 사이로 보이는 아폴로 벨트와 비키니 라인, 속옷, 코스튬 위 고간 윤곽(천 위의 부피감), 땀과 오일 광택, 근육 강조, 결박 연출(히트 줄기, 로프, 쇠사슬), 마사지 장면의 수건 한 장 |
| **처리하면 허용** | 엉덩이를 과하게 드러낸 구도. 이펙트, 그림자, 천으로 가리거나 프레임 밖으로 잘라 냄 (오늘 받은 노이르 예시의 보라색 히트 줄기 방식) |
| **불허** | 성기 묘사, 천이 비쳐 형태가 그대로 보이는 윤곽, 직접적인 성행위, 미성년으로 보이는 캐릭터의 성적 연출 |

### 4.3 자리별 단계

| 단계 | 자리 | 기준 |
|---|---|---|
| 1 (가장 약함) | 스토어 아이콘, 스토어 스크린샷, 광고, 첫 로딩 화면 | 코스튬을 제대로 입은 상태. 근육과 포즈로 어필. 연령 등급과 상관없이 누구에게나 보이는 자리라 한 단계 낮춤 |
| 2 | 스탠딩, 스토리, 로비, 전투 | 허용 범위까지 |
| 3 | 각성, 케어 룸 마사지, 인연 10 | 허용 범위 최대 + 처리하면 허용 |

- 스토어 연령 등급 신청은 출시 단계에서 3단계 그림 기준으로 함

### 4.4 가리는 방법 [임의 A4]
- **히트 이펙트**: 속성 색의 줄기, 불꽃, 바람, 얼음 (세계관의 히트 현상이라 어색하지 않음)
- 그림자, 수건, 찢어진 천, 벨트나 타월 같은 소품
- 프레임 밖으로 잘라 냄
- **모자이크와 블러는 쓰지 않음.** 그림의 질이 떨어져 보이고, 오히려 그 부분이 눈에 띔

### 4.5 검수 체크리스트 (Claude가 그림마다 확인)
1. 성인 체형인가
2. 불허 항목이 없는가
3. 쓰일 자리의 단계에 맞는가
4. 설정(색, 마스크, 소품)과 맞는가
5. 손가락, 관절, 소품 오류가 없는가
6. 속성 색이 읽히는가
7. **몸 전체가 화면 안에 들어오는가** [확정, 2026-11-17 사용자 규칙]
   - 팔, 손, 발, 부츠가 화면 밖으로 잘린 그림은 주 추천에 넣지 않음. 추천 목록 끝에 "이것도 멋있긴한데..."로 따로 붙임
   - `nai_gen.py sheet`가 선 그림이 테두리에 닿은 그림에 빨간 `CUT` 표시를 붙임 (이펙트는 테두리에 닿아도 괜찮음)
   - 각성 태그에 `full body, whole body in frame`을 넣으면 잘림이 크게 줄어듦 (룽웨이 20장 중 15장이 화면 안)
8. 손가락 수. 원근으로 크게 내민 손에서 여섯 손가락이 잘 나옴 → 고칠 때는 `nai_gen.py inpaint`로 손 부분만 다시 그림 (Opus에서 무료)

## 5. 케어 룸 마사지 장면

리텐션 문서 5.4의 케어 룸에서 쓰는 그림입니다.

- **구도**: 마사지 테이블에 엎드리거나 누운 선수, 수건 한 장, 오일 광택, 편안한 표정
- **매니저의 손은 그리지 않음** [임의 A5]. 매니저(플레이어)의 종을 정하지 않아야 누구나 자기를 대입할 수 있음. 대신 화면을 터치하면 손 모양 이펙트와 반응 대사가 나옴
- **캐릭터당 1장 + 변주 1장** [임의 A6]. 변주는 같은 그림을 인페인트로 바꿈 (수건 위치, 표정, 광택). 인연 5에서 해금
- 배경은 공용 케어 룸 배경 1장. 캐릭터는 흰 배경으로 생성해 합성
- 대사: 인연 단계별 3~5줄
- 태그 예: `lying on stomach, massage table, towel, oiled body, shiny fur, relaxed, eyes closed, from above, white background` + 캐릭터 고유 태그 + 스탠딩 레퍼런스

## 6. 파일 규칙 [임의 A7]

데이터 주도 구조에서 캐릭터를 추가할 때 "정해진 폴더에 그림 넣기"가 이 규칙입니다.

```
Art/Characters/{id}/
  standing.png        스탠딩
  awakened.png        각성
  sd_idle.png         SD 대기
  sd_dash.png         SD 돌진
  sd_down.png         SD 다운
  care_1.png          마사지
  care_2.png          마사지 변주
  bust_neutral.png    대화용 기본
  bust_smile.png      웃음
  bust_angry.png      화남
  bust_flustered.png  당황
  bond10.png          인연 10
  thumb_square.png    정사각 썸네일
  thumb_wide.png      가로 띠 썸네일
  source.json         태그, 시드, 모델, 레퍼런스 기록
```

- `{id}`는 영문 소문자: `leo`, `taiga`, `iceberg`, `volt`, `toro`, `zephyro`, `luca`, `golden_fang`, `laugh`, `noir`, `tusk`, `otty`, `jack`, `tanu`, `deathroll`, `longwei`, `reynard`, `rocket_rabbit`, `iron_fin`, `bernard`, `ghost_crow`, `mac`, `junior`, `hippo`
- 얼터: `leo_dark`, `noir_rebellion`, `toro_heart`
- 없는 그림은 빈 칸으로 두면 게임이 임시 그림을 대신 보여 줌. 데이터 검증 도구가 빠진 그림 목록을 알려 줌
