## 1. 한 줄 요약

3인 태그팀이 **당겨 쏘기**로 상대를 로프로 몰아 **다운**시키고, 다운된 상대에게 **플랜(핀폴, 서브미션, 링아웃)**을 고른 뒤 **다음 샷을 맞혀** 실행하면, **연타 힘겨루기**로 승부가 납니다. 팀이 함께 쓰는 **관중 열기**가 전투 전체를 달구고, 피날레와 필살기에서 크게 효과를 냅니다.

## 3. 팀과 캐릭터

### 3.1 편성
- 3인 편성. 링 안에 1명, 링 밖에 2명 [확정]
- 슬롯마다 세컨드 1명을 붙임. 한 팀은 선수 3명 + 세컨드 3명 (3.4) [확정 개념]
- 상대 팀은 스테이지마다 1~3인. 1인이면 태그를 하지 않는 대신 스태미나가 큰 보스로 둠 [임의 2]
- 같은 체인 역할을 중복해서 편성해도 됨. 대신 체인을 완성할 수 없음 [임의 3]

### 3.2 캐릭터 한 명이 가진 전투 데이터
| 항목 | 내용 |
|---|---|
| 진영 | 페이스(히어로) 또는 힐(빌런) [확정 개념] |
| 속성 | 열혈, 냉정, 개방, 성실, 음침 중 하나 (3.3) [확정 개념] |
| 체인 역할 | 선봉, 연결, 마무리 중 하나 [확정] |
| 타입 | 스트라이커, 쇼메이커, 그래플러, 스탬피더, 하이플라이어 중 하나 (5.3) [확정 개념] |
| 스태미나 | 0이 되면 다운 |
| 파워 | 타격 위력. 힘겨루기에서 공격할 때 연타 한 번의 무게 |
| 근성 | 다운 회복 속도. 힘겨루기에서 버틸 때 연타 한 번의 무게 |
| 열기 의존도 | 일반 전투 성능이 관중 열기에 얼마나 좌우되는지 (9.3) [확정 개념] |
| 어필 성능 | 어필 한 번에 오르는 열기 양 |
| 필살기 | 1개. 전신 컷인과 함께 나감 |
| 특성 | 1개. 스테이지 기믹이나 특정 상황에서 보정 (예: 로프 근처에서 위력 상승) |
| 세컨드 성능 | 세컨드로 붙었을 때 짝 선수에게 주는 능력치와 세컨드 스킬 (3.4) |

캐릭터 차이는 **피날레를 어떻게 끝내느냐가 아니라 전투 중에 어떻게 움직이느냐**에서 나옵니다. 플랜 선택은 그 판의 상황이 정합니다 [확정].

### 3.3 속성 [확정 개념, 배율과 적용 범위는 임의 4]
원소가 아니라 **선수의 성격**을 속성으로 씁니다.

| 속성 | 색 | 유리한 상대 | 불리한 상대 |
|---|---|---|---|
| 열혈 | 빨강 | 개방 | 냉정 |
| 냉정 | 파랑 | 열혈 | 개방 |
| 개방 | 초록 | 냉정 | 열혈 |
| 성실 | 노랑 | 음침 | 음침 |
| 음침 | 보라 | 성실 | 성실 |

- 열혈 → 개방 → 냉정 → 열혈 순환 (화살표 방향으로 유리)
- 성실과 음침은 서로에게 유리. 둘이 만나면 서로 큰 피해를 줌
- 유리하면 타격 위력 ×1.3, 불리하면 ×0.8 [임의 4]
- 일반 타격에만 적용하고 연타 힘겨루기에는 적용하지 않음. 피날레는 열기와 능력치로 결정되게 함 [임의 4]
- 속성은 진영과 별개. 음침한 히어로, 성실한 빌런이 있을 수 있음
- 참고 일러스트를 나누면 (예시): 열혈 = 사자, 호랑이 / 냉정 = 곰, 푸른 늑대 / 개방 = 황소, 회백색 사자 / 성실 = 노란 고양이, 흰 늑대 / 음침 = 하이에나, 흑표범

### 3.4 세컨드 [확정 개념, 세부는 임의 29~32]
레슬링에서 링 밖에 붙어 선수를 돕는 동료(세컨드)를 어시스트 시스템으로 씁니다. 월드 플리퍼의 어시스트 슬롯과 같은 역할입니다.

- 슬롯마다 선수 1명 + 세컨드 1명
- 모든 캐릭터는 **선수 성능**과 **세컨드 성능**을 따로 가짐. 등급이 낮아도 세컨드 성능이 좋은 캐릭터가 있음
- 세컨드는 짝 선수에게 자기 능력치의 20%를 더해 주고, 세컨드 스킬 1개(상시 효과)를 줌 [임의 29]
- **개입**: 짝 선수가 링 안에 있을 때, 피날레 힘겨루기 도중 한 판에 한 번 쓸 수 있음 [임의 30]
  - 페이스 세컨드: 응원. 3초 동안 연타 한 번의 무게 ×1.5
  - 힐 세컨드: 심판의 주의를 돌림. 상대 쪽 카운트나 게이지가 2초 동안 멈춤. 대신 심판 경고 1회 누적
- 세컨드는 화면 하단 초상화 옆에 작게 표시하고, 개입할 때만 짧은 컷인으로 등장 [임의 31]. 링 밖 대기 선수와 섞이면 화면이 복잡해지기 때문
- 같은 선수(기본 카드와 얼터 카드 포함)는 한 팀에 한 번만 넣을 수 있음 [임의 32]
- 효과: 지난 픽업 선수, 드롭 선수, 낮은 등급 선수가 세컨드로 계속 쓰임 [확정 근거]

## 4. 턴 구조

### 4.1 내 턴
1. **태그** (선택, 턴 소모 없음, 1회) [확정]
2. **행동 1개**: 샷, 어필, 필살기 샷 중 하나
3. 판정 결과에 따라 다운이나 피날레가 발생함

### 4.2 상대 턴 [임의 6]
- 상대는 매 턴 행동하지 않습니다. 몬스터 스트라이크처럼 **행동 카운트**가 0이 되면 행동하고, 카운트는 다시 3으로 돌아갑니다.
- 상대 행동: 돌진 공격, 태그, 어필, 다운된 내 선수에게 피날레 시도
- 이유: 유저가 쏘는 시간이 전투의 대부분이 되도록 하고, "상대가 행동하기 전에 끝낼까, 버틸까"라는 판단을 남기기 위해서입니다.

### 4.3 턴 제한 [임의 7]
- 20턴 안에 이기지 못하면 패배합니다. 스테이지마다 바꿀 수 있습니다.

## 5. 샷과 링 물리

### 5.1 당겨 쏘기
- 당기는 방향이 쏘는 방향, 당긴 길이가 세기
- **조준 가이드는 첫 번째 반사 지점까지만** 보여 주고, 멈추는 위치는 보여 주지 않음 [임의 8]. 착지 위치를 보여 주면 퍼즐의 답이 되어 버린다는 지적을 반영했습니다.
- 바닥 마찰로 감속하다가 멈춤

### 5.2 로프
- 로프는 튕겨 내는 벽
- 내 선수가 로프에 한 번 튕길 때마다 다음 타격 위력 +15% (최대 3회) [임의 9]
- 상대가 맞고 로프에 튕겨 돌아올 때 다시 맞히면 **라리아트 보너스** (위력 ×1.5, 열기 상승) [임의 10]

### 5.3 타입 [확정 개념, 동작 정의는 임의 5]
| 타입 | 동작 | 주로 만드는 상황 |
|---|---|---|
| 스트라이커 | 로프를 거치지 않은 직접 타격의 위력이 큼. 맞은 상대가 멀리 밀려남 | 상대를 로프 쪽으로 보냄 → 링아웃 |
| 쇼메이커 | 로프 반동 보너스 2배. 반동할 때마다 관중 열기도 추가로 오름 | 열기를 띄우고 다운을 빨리 만듦 |
| 그래플러 | 처음 닿은 상대를 붙잡고, **링 중앙 방향으로 자동으로** 던짐 | 상대를 중앙으로 옮김 → 서브미션 |
| 스탬피더 | 상대에게 부딪혀도 멈추지 않고 뚫고 지나감. 로프에 튕겨 다시 맞힐 수 있음 | 한 샷에 여러 번 타격 |
| 하이플라이어 | 로프에 처음 닿으면 뛰어올라 착지 지점 주변을 넓게 타격 | 멀리 쓰러진 상대에게도 닿기 쉬움 → 핀폴 진입 |

- 원래 "돌진"으로 적었던 밀어내기는 스트라이커에 합치고, 스탬피더는 "뚫기"로 정의했습니다
- **타입 사이에는 상성을 두지 않음** [임의 5]. 상성이 속성과 타입 두 겹이면 유저가 매번 두 표를 계산해야 함. 타입의 유불리는 특수 매치가 만듦 (예: 케이지 매치에서는 링아웃을 만드는 스트라이커의 장점이 줄어듦)
- 그래플러가 던지는 방향을 자동으로 정한 이유는, 길이를 유저가 정확히 통제하기 어렵기 때문
- 타입은 나중에 추가할 수 있음

## 6. 스태미나와 다운

- 체력이 아니라 **스태미나**를 씀. 0이 되면 다운 [확정]
- 다운된 선수는 **매 턴 스태미나를 회복**하고, 일정량이 차면 일어남 [확정]
  - 회복량: 턴마다 최대 스태미나의 15% + 근성 보정 [임의 11]
  - 일어나는 기준: 최대치의 30%까지 회복하면 기상 → 보통 내 턴 2번 정도 여유가 있음
- 링 밖에서 대기 중인 선수는 매 턴 최대치의 5%를 회복함 [임의 12]. 태그로 빼 주면 체력을 아낄 수 있습니다.
- **다운된 내 선수도 태그로 빼낼 수 있음** [임의 13]. 빠진 선수는 낮은 스태미나로 대기하다가 서서히 회복합니다. 상대의 피날레를 피하는 구조 수단이 되고, 팀 전체 버티기 판단이 생깁니다.

## 7. 피날레 플랜

### 7.1 흐름 [확정]
1. 상대 다운
2. 플랜 선택: 핀폴, 서브미션, 링아웃
3. **다음 샷이 다운된 상대에게 닿아야** 실행됨
4. 실행되면 연타 힘겨루기(8장)

- 다운이 이어지는 동안에는 매 턴 쏘기 전에 플랜을 바꿀 수 있음 [임의 14]
- 샷이 닿지 않으면 플랜은 유지되고, 다운 시간만 줄어듦

### 7.2 플랜별 실행 조건과 유불리
| 플랜 | 실행 조건 | 유리한 상황 | 불리한 상황 |
|---|---|---|---|
| 핀폴 | 닿기만 하면 됨 | 상대 스태미나가 적음 | 회복이 진행될수록 쉽게 빠져나옴 |
| 서브미션 | 닿기만 하면 됨 | 상대가 링 중앙에 있음 | 로프 근처면 상대 저항이 1.5배이고, 상대가 이기면 로프 브레이크 [임의 15] |
| 링아웃 | 닿은 뒤 상대가 **일정 속도 이상으로 로프에 부딪혀야** 함 | 상대가 로프 근처에 있음. 스트라이커 | 중앙에서는 속도가 부족해 실패하기 쉬움 |

"로프 근처"의 기준은 로프에서 유닛 지름의 1.5배 이내입니다 [임의 15].

## 8. 연타 힘겨루기 [확정 개념]

### 8.1 공통
- 게이지 0~100. 100 쪽이 공격 측, 0 쪽이 방어 측
- **시작 위치** = 50 + (관중 열기 보정) − (상대 남은 스태미나 보정) [임의 16]
- 공격 측의 연타 한 번 = 파워 × 열기 배율만큼 게이지를 밀어 올림
- 방어 측(AI)은 초당 일정량을 밀어 내림 = 근성 × 남은 스태미나 비율
- 내가 방어하는 쪽일 때는 반대로 내가 연타해서 밀어 내림
- 한 판에 2~4번 정도 나오도록 스태미나와 회복량을 맞춤 [확정 목표]

### 8.2 플랜별 규칙 [임의 17]
| 플랜 | 입력 | 승리 조건 | 실패 조건 |
|---|---|---|---|
| 핀폴 | 연타 | 게이지가 60 이상인 동안 1초마다 카운트가 진행됨. 3카운트면 승리 | 게이지가 0에 닿으면 킥아웃 |
| 서브미션 | 좌우 번갈아 연타 | 5초 안에 게이지 100 → 기브업 | 5초가 지나거나 게이지 0 → 탈출 |
| 링아웃 | 누르고 있다가 신호에 맞춰 연타 | 게이지 100 → 상대가 로프 밖으로 떨어짐 | 게이지 0 → 상대가 로프를 잡고 복귀 |

### 8.3 실패한 뒤
- 상대가 일어나고 스태미나를 최대치의 30%까지 회복 [임의 18]
- 관중 열기가 조금 오름 (니어폴 연출. 아깝게 놓친 장면은 관중이 달아오름) [임의 18]

### 8.4 세컨드 개입
- 힘겨루기 도중 개입 버튼이 나타남. 한 판에 한 번 (3.4)
- 상대 세컨드도 개입할 수 있음. 내가 버티는 쪽일 때 상대 힐 세컨드가 끼어들면 게이지가 잠시 상대 쪽으로 쏠림

## 9. 관중 열기 [확정 핵심]

### 9.1 기본
- 팀이 함께 쓰는 게이지, 0~100 [확정]
- 잘 싸우면 서서히 오르고, 가만히 있으면 내려감 [확정]

### 9.2 오르내림 [임의 19]
| 오르는 경우 | 양 |
|---|---|
| 로프 반동 타격 | +5 (반동 1회당) |
| 라리아트 보너스 | +10 |
| 다운 유발 | +10 |
| 태그 체인 한 칸 | +5 |
| 니어폴 (피날레 실패) | +10 |
| 어필 | 캐릭터별로 +25~40 |

| 내려가는 경우 | 양 |
|---|---|
| 매 턴 | −5 |
| 아무도 맞히지 못한 턴 | 추가 −10 |
| 화려한 플레이(반동 2회 이상, 라리아트, 공중기) 직후 1턴 | 감소 없음 |

### 9.3 효과
- **일반 전투 성능**: 열기 0에서 −10%, 100에서 +10%까지 위력이 오르내림 [확정 개념, 수치 임의 20]
- **열기 의존 캐릭터**: 같은 폭이 ±30% [임의 20]
- **필살기 위력과 힘겨루기**: 열기 0에서 ×0.6, 100에서 ×1.6 [확정 개념, 수치 임의 20]

### 9.4 어필 [확정]
- 한 턴을 써서 열기를 크게 끌어올림
- 같은 선수가 연속으로 어필하면 두 번째부터 효과 절반 [임의 21]
- 어필이 정말 쓸 만한지, 필수가 되지 않는지는 **프로토타입에서 검증** [확정]

### 9.5 페이스와 힐 [임의 22]
| | 어필 이름 | 열기 상승 | 대가 |
|---|---|---|---|
| 페이스 | 응원 유도 | 보통 | 없음 |
| 힐 | 도발, 반칙 | 페이스의 1.5배 | 심판 경고 누적. 3회째부터는 다음 힘겨루기를 불리한 위치(−10)에서 시작 |

## 10. 태그 [확정]

- 행동 전 1회, **턴 소모 없음**
- **방금 나간 선수는 1턴 동안 다시 들어올 수 없음**
- 나가는 선수는 링 어디에서든 나갈 수 있음 (중앙 제한 없음)
- 나간 선수는 **자기 위치에서 가장 가까운 로프 바로 밖**에서 대기함
- 들어오는 선수는 **자기 대기 위치에서 가장 가까운 로프 안쪽**으로 진입함
- 대기 위치는 대기하는 동안 움직이지 않음 [임의 23]
- 상대 팀도 같은 규칙을 따름

## 11. 태그 체인과 필살기

### 11.1 태그 체인 [확정]
- 3칸: 선봉 → 연결 → 마무리
- 해당 역할의 선수가 **자기 턴에 상대를 맞혀야** 칸이 켜짐
- 순서가 맞지 않는 역할이 맞히면 무시함. 체인이 끊기지는 않고, 다음에 필요한 역할만 받음 [임의 24]

### 11.2 필살기 [임의 25]
- **개인 필살기**: 선수마다 게이지가 있고 맞힐수록 참. 가득 차면 샷 대신 필살기 샷을 쏠 수 있음. 전신 스킬 컷인
- **합동 필살기**: 체인 3칸이 켜지면, 마무리 선수의 다음 샷이 합동 필살기가 됨. 세 명이 함께 나오는 컷인. 쓰면 체인이 초기화됨
- 두 필살기 모두 위력에 관중 열기 배율(9.3)이 크게 걸림

## 12. 승패

- **승리**: 상대 팀 중 **한 명에게** 피날레(핀폴, 서브미션, 링아웃)를 성공하면 팀 승리 [임의 26]. 실제 태그 매치 규칙과 같고, 한 판의 길이를 짧게 유지할 수 있습니다.
- **패배**: 내 선수 중 한 명이 피날레를 당하거나, 턴 제한을 넘기면 패배 [임의 26]
- **클리어 기록**: 턴 수, 피날레 종류, 남은 스태미나를 기록함. 소탕에 쓸 기준은 소탕을 개발할 때 정함 [확정 보류]

## 13. 스테이지 기믹과 특수 매치 [확정 개념, 목록은 임의 27]

| 매치 | 규칙 변경 | 바뀌는 판단 |
|---|---|---|
| 케이지 매치 | 링아웃 불가 | 핀폴과 서브미션만으로 끝내야 함 |
| 노 로프 브레이크 | 로프 브레이크 없음 | 로프 근처에서도 서브미션이 강해짐 |
| 서브미션 매치 | 기브업으로만 승리 | 잡기형과 상대 위치 관리가 핵심 |
| 폴스 카운트 애니웨어 | 링아웃 대신 링 밖에서도 핀폴 가능 | 로프 근처 다운도 핀폴 기회가 됨 |
| 에이프런 봉쇄 | 한쪽 면에서는 태그 진입 불가 | 대기 위치 관리가 중요해짐 |
| 핸디캡 매치 | 1인 보스 대 내 3인 | 보스 스태미나가 크고 행동 카운트가 짧음 |
| 랜버잭 등 이벤트 매치 | 로프 밖에 장애물 | 링아웃 대신 특수 효과 |

## 14. 캐릭터를 바꿔 들어갈 명분과의 연결

| 장치 | 이 전투에서 생기는 이유 |
|---|---|
| 속성 상성 | 상대 속성에 맞춰 편성 |
| 타입 | 매치 규칙에 맞는 피날레 상황을 만들 수 있는 선수 (케이지면 링아웃을 만드는 스트라이커의 장점이 줄어듦) |
| 세컨드 | 지난 픽업 선수와 낮은 등급 선수도 세컨드로 계속 쓰임 |
| 체인 역할 | 선봉, 연결, 마무리를 갖춰야 합동 필살기 |
| 진영 | 힐 전용 매치, 페이스 전용 매치 |
| 이벤트 특효 | 신규 캐릭터 기록 갱신 → 소탕 보상 상승 |

## 15. 프로토타입에서 확인할 것

1. 한 판 길이: 목표 3~5분 [임의 28]
2. 연타 힘겨루기 횟수: 한 판에 2~4회 [확정 목표]
3. 어필 사용률: 쓰는 판과 안 쓰는 판이 갈리는지. 매 판 같은 턴에 쓰면 실패
4. 태그 빈도: 매 턴 태그가 정답이 되지 않는지
5. 다운까지 걸리는 턴 수와 다운 후 기상까지의 여유
6. 길이 통제가 어려운 상황에서 링아웃 성공률이 너무 낮지 않은지

## 16. 이 문서에 없는 것 (다음 작업 후보)

- 가챠, 캐릭터 성장, 등급 구조
- 소탕 기준 (보류 [확정])
- 일일/주간/월간 콘텐츠 구조와 랭킹
- 캐릭터 에셋 규격: 작은 유닛, 스탠딩, 스킬 컷인, 핀폴 컷인(누르는 포즈와 눌리는 포즈)
